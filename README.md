# Vivimagic GC Suite (v2.0.0)

Publisher: [Vivimagic](https://github.com/Vivimagic)  
Repository: https://github.com/Vivimagic/GameCube-Bridge-Studio  
Changelog: [CHANGELOG.md](./CHANGELOG.md)

Universal 4-port GameCube Controller Adapter driver suite, live controller & rumble tester, 1000 Hz MMCSS Xbox 360 / DualShock 4 bridge, automatic window-focus Dolphin/Slippi USB handover, and RP2040 Firmware & SDK workbench for **Windows**, **macOS**, and **Linux / Steam Deck**.

## Supported Adapters (Wii U / Switch Mode `057E:0337`)
- Official Nintendo WUP-028
- Mayflash W012 (4-Port)
- MEIRIYFA 4-Port Adapter
- Nyko / Kelux / Piranha / Intec / Hitbox clones
- Input Integrity Lossless & Handheld Legend GC Pocket+
- Universal Legacy PC-Mode / 2-Port / Raphnet / 8BitDo Gbros fallback

## Automated Cross-Platform Releases (Windows + macOS + Linux)
Pushing a version tag (e.g. `v2.0.0`) or clicking **Actions -> Build v2.0.0 Release -> Run workflow** automatically compiles and publishes:
- **Windows**: `Vivimagic-GC-Suite-v2.0.0-win-x64.exe`
- **macOS**: `Vivimagic-GC-Suite-v2.0.0-macos-universal.dmg` & `Vivimagic-GC-Suite-v2.0.0-macos-app.zip`
- **Linux / Steam Deck**: `vivimagic-gc-suite_2.0.0_all.deb`, `Vivimagic-GC-Suite-v2.0.0-linux.tar.gz`, & `Vivimagic-GC-Suite-v2.0.0-linux.sh`
- **Checksums**: `SHA256SUMS.txt`
